# SH Notes

**[Открыть библиотеку конспектов →](https://slavikhom.github.io/SHNotes/)**

Математическая логика и дискретная математика: готовые PDF с авторским оформлением и веб-читалкой.

## Как обновлять

Добавьте или замените готовый PDF в `MathLog/` или `DM/` и отправьте изменения в ветку `main`.
GitHub Actions сам построит каталог, обложки и оглавления, затем опубликует сайт на GitHub Pages.
Удалённый из репозитория PDF исчезнет из следующей публикации. Собирать сайт на своём компьютере не нужно.

Название, номер лекции и описание считываются с обложки SH Notes; число страниц и разделы — из PDF.
Для PDF другого оформления используется заголовок из метаданных или имя файла.
Вручную вести список лекций не требуется. Встроенные ссылки на разделы, поиск по тексту, масштаб и скачивание доступны в читалке.
Место чтения сохраняется только в браузере на текущем устройстве.

## Структура

- `MathLog/`, `DM/` — только готовые PDF, без вложенных папок.
- `site/` — интерфейс, сборщик каталога и локальная копия Mozilla PDF.js 6.3.289 (Apache-2.0, см. `site/vendor/LICENSE`).
- `.github/workflows/pages.yml` — автоматическая сборка и публикация.

LaTeX, видео, расшифровки и промежуточные материалы остаются за пределами этого репозитория.

## Однократная настройка GitHub

В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
Если первая сборка произошла до включения Pages, запустите **Actions → Publish SH Notes → Run workflow**.
Дальше всё обновляется после каждого изменения PDF или сайта в `main`.
Неудачная сборка не заменяет последнюю рабочую публикацию.

## Локальная проверка

```sh
python -m pip install -r site/requirements.txt
python site/build.py
python site/serve.py
```

Откройте адрес, который напечатает сервер. `_site/` — временный результат сборки и не входит в Git.
