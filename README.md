# SH Notes

Конспекты по математической логике и дискретной математике: определения, доказательства, примеры и схемы в едином оформлении.

**[Читать конспекты →](https://slavikhom.github.io/SHNotes/)**

## Курсы

- **[Матлог](MathLog/)**
- **[Дискретка](DM/)**

На сайте доступны оглавление с переходами, поиск по тексту, масштабирование и скачивание PDF. Читалка запоминает страницу, точное место и масштаб на вашем устройстве. Конспекты остаются готовыми PDF; их содержание и вёрстка не меняются.

На телефоне или планшете листайте конспект одним пальцем, а для увеличения разведите два пальца прямо на PDF. Увеличенный документ можно двигать в любом направлении. Кнопка «Ширина» возвращает страницу к ширине экрана; оглавление открывается кнопкой слева вверху.

На компьютере используйте Ctrl + колесо мыши в читалке: масштаб PDF меняется вокруг курсора, а интерфейс сохраняет свой размер.

В меню «⋯» доступны именованные закладки, ссылка на текущее место и сохранение выбранной лекции для чтения без интернета. Сохраняются PDF и файлы читалки; готовность подтверждается только после полной загрузки. Сохранённые лекции можно удалить через «Без интернета» внизу библиотеки. Браузер может очистить эти копии при нехватке места или очистке данных сайта.

В поиске библиотеки выберите «В тексте PDF», чтобы искать по всем страницам выбранного предмета и переходить к найденным местам. Индекс создаётся автоматически из текстового слоя актуальных PDF. Страницы, содержащие только изображение без текста, требуют предварительного OCR.

В режиме чтения кнопка «×» всегда возвращает обычную панель, включая узкий экран и горизонтальную ориентацию. При ошибке загрузки доступны повторная попытка и открытие PDF отдельно.

## Проверки сайта

После изменений: `python site/test_build.py`, `python site/build.py` и `node --test site/test_reader_touch.mjs site/test_reading_state.mjs`. Для браузерных проверок: `cd site`, `npm ci --ignore-scripts`, `npx playwright install chromium webkit`, `npm test`. Отдельный запуск WebKit: `BROWSER=webkit node --test site/test_browser.cjs` (в PowerShell: `$env:BROWSER='webkit'`).

GitHub Actions проверяет читалку в Chromium и WebKit перед публикацией: ширины от 320 до 1366 px, поворот экрана, сохранение позиции, закладки, поиск, загрузку без сети и обработку ошибок. Тестовый сервер использует `/SHNotes/`, чтобы проверять пути и область service worker так же, как на GitHub Pages. Проверки жестов Chromium дополняют модульные проверки Safari gesture events; реальные устройства остаются отдельной ручной проверкой.

PDF можно также открыть или скачать непосредственно из папок курсов. Библиотека автоматически обновляется вместе с конспектами в этом репозитории.
