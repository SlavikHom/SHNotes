# SH Notes

Конспекты по математической логике и дискретной математике: определения, доказательства, примеры и схемы в едином оформлении.

**[Читать конспекты →](https://slavikhom.github.io/SHNotes/)**

## Курсы

- **[Матлог](MathLog/)** — язык и исчисление высказываний, истинность и доказуемость, полнота, интуиционизм.
- **[Дискретка](DM/)** — ориентированные графы, деревья, эйлеровы обходы и связанные теоремы.

На сайте доступны оглавление с переходами, поиск по тексту, масштабирование и скачивание PDF. Читалка запоминает последнюю открытую страницу на вашем устройстве.

PDF можно также открыть или скачать непосредственно из папок курсов. Библиотека автоматически обновляется вместе с конспектами в этом репозитории.

Нашли неточность? [Сообщите об ошибке](https://github.com/SlavikHom/SHNotes/issues), указав лекцию и страницу.
